公共网络
{{range .DNSRows}}{{template "dns-row" .}}{{end}}
每行填写一个 IPv4 DNS 地址。全部留空时，NAT 使用 1.1.1.1 和 8.8.8.8，Proxy ARP 使用地址池所在 /24 的 .1 和 1.1.1.1。网关提供 DNS 时，可以填写它的地址。
填写 IPv4 目标网段，多项用英文逗号分隔。留空允许全部 IPv4 目标。仅访问局域网时填写 LAN 网段，例如 192.168.0.0/24。全局上网还需在客户端开启全隧道。
NAT 模式 填写一个对齐的 IPv4 CIDR 或起始 IP-结束 IP，留空使用 10.66.0.0/24。选用独立网段，避开宿主机、家里及客户端所在地的网络。
Proxy ARP 模式 填写局域网内的一个地址范围或对齐的 IPv4 CIDR，例如 192.168.0.201-192.168.0.210 或 192.168.0.240/29。排除 DHCP 地址、已占用地址及局域网的网络和广播地址。留空使用示例中的地址范围。
填写宿主机所在局域网的网段。留空时从地址池推导 /24，例如 192.168.0.0/24。实际网段使用其他掩码时请手动填写。
填写发往局域网以外的 VPN 流量的下一跳。网关必须与宿主机直连，地址位于局域网内、地址池外，且与宿主机地址不同。网关需支持转发，并提供 NAT 或正确的回程路由。留空使用宿主机原有路由。
